# MONNAVI

A premium, bilingual technology-company homepage for MONNAVI.

## What it includes

- Spanish-first interface with an ES/EN language switch
- Responsive dark-mode design
- Solutions for software, AI, automation, IoT, data, and digitalization
- Industry, process, technology, concept-work, and contact sections
- Next.js, TypeScript, and Tailwind CSS structure

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.
